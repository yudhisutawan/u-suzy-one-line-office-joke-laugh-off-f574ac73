one original one-line joke about office life.

## The line

> I told my boss I needed a mental health day. He asked if lunch would be long enough.

(84 characters — under the 200-character gate.)

## How it works

`main.py` is stdlib-only. It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -S -P main.py
cat /tmp/out/entry.txt
```
